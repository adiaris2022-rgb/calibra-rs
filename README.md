# CALIBRA RS MVP
Medical Equipment Control Tower.

## MVP architecture
- Node.js + Express web app/PWA foundation
- PostgreSQL via `DATABASE_URL`
- `/health` health check
- `/api/dashboard` demo dashboard API
- Frontend in `public/`

Next: authentication/roles, Excel import, equipment schema, QR mapping/scanning, inspections, evidence upload, real-time events, work orders, certificates, audit log.
